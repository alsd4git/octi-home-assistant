# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/alsd4git/octi-home-assistant/security/advisories/new).
Do not open a public issue for a security vulnerability.

Include only the information needed to reproduce and assess the issue. Never attach or paste a
real Octi linking payload, account ID, device password, Authorization header, encryption keyset,
clipboard content, installed-app data or decrypted module payload. Replace sensitive values with
synthetic examples and remove them from screenshots and logs.

You should receive an acknowledgement within seven days. The report will be assessed privately,
and any disclosure or release timeline will be coordinated after the impact and remediation are
understood.

## Supported versions

Security fixes are provided for the latest published release. Before the first release, only the
current default branch is maintained. Users should upgrade to the newest release before reporting
an issue that may already have been fixed.

## Scope

Reports about this Home Assistant integration belong here. Vulnerabilities in Octi itself should be
reported to the upstream project using its own security and contribution channels.
